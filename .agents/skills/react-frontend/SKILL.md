# React Frontend Development Skill

## Technology Stack
- React
- TypeScript
- Vite
- Tailwind CSS v4

## Development Rules

1. Always use TypeScript (.tsx and .ts).
2. Use functional components and React hooks.
3. Prefer reusable components.
4. Use proper TypeScript interfaces and types.
5. Avoid unnecessary dependencies.
6. Follow clean code principles.
7. Avoid unnecessary use of useEffect.
8. Keep components small and maintainable.

## UI/UX Guidelines

1. Create modern, professional interfaces.
2. Follow responsive design principles.
3. Use Tailwind CSS v4.
4. Maintain consistent spacing and typography.
5. Provide loading, error and empty states.
6. Prioritize accessibility.

## Code Quality

1. Avoid any unless absolutely necessary.
2. Avoid duplicated code.
3. Use meaningful variable names.
4. Handle errors properly.
5. Explain architectural decisions when necessary.

## Important

Before implementing a feature:
1. Understand the existing project structure.
2. Inspect existing components and conventions.
3. Propose the implementation approach.
4. Implement without unnecessarily changing existing code.
5. Verify the implementation.
